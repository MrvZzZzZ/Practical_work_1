## Задачи и результаты

### Задача 1: Обнаружение фейковых новостей (Fake News Detection)
- **Цель:** Построить модель бинарной классификации для определения достоверности новостей (`REAL` / `FAKE`) с точностью >90%.
- **Подход:** Векторизация текста с помощью `TfidfVectorizer` (с удалением стоп-слов, учетом n-gram и фильтрацией частых слов) и обучение линейного классификатора `PassiveAggressiveClassifier`.
- **Датасет:** `fake_news.csv` (загружается автоматически из Yandex Cloud).
- **Результат:** Точность **~94%**. Построены нормализованная матрица ошибок и график метрик (Precision, Recall, F1-score).

### Задача 2: Диагностика болезни Паркинсона
- **Цель:** Предсказать наличие болезни Паркинсона на ранних стадиях по акустическим характеристикам голоса.
- **Подход:** Градиентный бустинг `XGBClassifier`, подбор гиперпараметров через `GridSearchCV`, оценка устойчивости модели с помощью `RepeatedStratifiedKFold` (50 фолдов).
- **Датасет:** UCI ML Parkinsons (`parkinsons.data`).
- **Результат:** Точность на тестовой выборке **~92.3%**, средняя точность при кросс-валидации **~91.2% ± 0.04**. Визуализированы важность признаков (`feature_importances_`) и детальный отчет классификации.

### Задача 3: Творческая. Классификация свечных паттернов
- **Цель:** Разработать модель для распознавания 16 основных свечных паттернов + класс `"No Pattern"` на синтетических данных с добавлением шума.
- **Подход:** 
  - Ручная генерация реалистичных OHLC-данных с параметризацией тел, теней и гэпов.
  - Инженерия признаков: соотношения тела/диапазона, позиции закрытия/открытия, индикатор Doji, гэпы между свечами.
  - Обучение многоклассового `XGBClassifier` (`objective='multi:softmax'`) с балансировкой весов классов (`compute_sample_weight`).
- **Результат:** Точность **~99.6%**. Модель уверенно различает сложные односвечные, двухсвечные и трехсвечные паттерны даже при наличии шума и вариаций цены.
